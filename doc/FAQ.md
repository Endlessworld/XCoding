# XAgent 常见问题解答

## ❓ 运行相关问题

### Q1: 启动时提示"找不到Java环境"
**A**: 请确认已安装JDK 17或更高版本，并且已经配置好环境变量：
```bash
java -version
```
如果显示Java版本低于17，请升级JDK版本。

### Q2: 模型调用失败，提示API密钥错误
**A**: 检查以下几点：
1. 确认环境变量配置正确，API密钥没有拼写错误
2. 确认API密钥有权限访问对应的模型服务
3. 确认网络可以正常访问API端点，没有被防火墙或代理拦截
4. 检查账户余额是否充足

### Q3: IDE中无法连接到XAgent
**A**: 排查步骤：
1. 先在终端直接运行`java -jar XAgent.jar`，确认可以正常启动
2. 检查IDE中的ACP配置路径是否正确，jar包路径没有空格或特殊字符
3. 查看IDE的AI Assistant日志，确认具体错误信息
4. 尝试重启IDE和XAgent进程

### Q4: 运行时提示"权限被拒绝"
**A**: 文件操作权限问题：
1. 确认XAgent的工作目录设置正确
2. 确认你对要操作的文件/目录有读写权限
3. Windows系统可能需要管理员权限才能操作某些目录
4. 不要尝试访问系统目录或其他受限目录

## 🛠️ 工具使用相关问题

### Q1: read_file读取文件时提示"文件不存在"
**A**: 
1. 确认文件路径是绝对路径，且没有拼写错误
2. 确认文件确实在工作目录范围内
3. Windows系统注意路径分隔符使用`\`或双斜杠`\\`
4. 文件名大小写敏感（Linux/macOS系统）

### Q2: edit_file替换失败，提示"找不到匹配的文本"
**A**:
1. 确认要替换的文本和文件中的内容完全一致，包括空格、换行符、缩进
2. 可以先使用`read_file`读取文件内容，复制要替换的部分
3. 注意换行符的差异（Windows是\r\n，Linux是\n）
4. 如果文本太长，可以尝试缩短匹配长度，但要保持唯一性

### Q3: grep搜索结果为空
**A**:
1. 确认搜索关键词正确，大小写匹配
2. 确认搜索目录和文件过滤模式正确
3. 如果关键词包含特殊字符，可能需要转义
4. 确认文件确实包含该内容，且不在.gitignore排除列表中

### Q4: Bash命令执行超时
**A**:
1. 增加超时时间参数（单位毫秒），最长可以设置为600000（10分钟）
2. 对于特别长的运行任务，使用后台运行模式，通过`BashOutput`查看进度
3. 确认命令本身没有问题，可以先在终端手动执行验证
4. 如果是网络相关命令，确认网络连接正常

## 🔧 功能相关问题

### Q1: 上下文太长导致响应变慢或出错
**A**:
1. XAgent会自动管理上下文，超出限制时会自动清理旧的消息
2. 对于特别大的文件，使用分页读取，不要一次性读取全部内容
3. 超长的工具输出会自动转换为指针，需要时使用`contextCacheTool`获取
4. 可以通过"清空上下文"指令手动清除会话历史

### Q2: 工具调用总是重复执行
**A**:
这是工具重试机制在生效，当工具调用失败时会自动重试最多2次：
1. 检查工具调用是否真的失败，可能只是响应慢
2. 如果不需要重试，可以提示"不需要重试，直接返回结果"
3. 确认网络连接是否稳定，API服务是否正常

### Q3: 任务列表功能不生效
**A**:
1. 确认你的IDE/客户端支持ACP Plan模式
2. 任务状态必须是大写的PENDING/IN_PROGRESS/COMPLETED
3. 优先级必须是大写的HIGH/MEDIUM/LOW
4. 尝试重新发起任务请求

### Q4: MCP服务器工具不显示
**A**:
1. 确认MCP服务器配置正确，命令和路径没有错误
2. 检查MCP服务器是否可以独立运行，没有报错
3. 查看XAgent启动日志，确认MCP服务器加载成功
4. 重启XAgent进程重新加载MCP配置

## 🚀 性能相关问题

### Q1: XAgent启动很慢
**A**:
1. JVM模式下启动需要1-2秒，属于正常现象
2. 可以使用GraalVM原生编译版本，启动时间缩短到0.1-0.5秒
3. 确认你的系统资源充足，没有其他进程占用过多CPU/内存

### Q2: 响应时间很长
**A**:
1. 可能是AI模型推理时间较长，特别是对于复杂任务
2. 检查网络连接到AI服务的延迟是否过高
3. 可以尝试切换到更快的模型服务
4. 减少上下文长度可以加快响应速度

### Q3: 内存占用过高
**A**:
1. JVM模式下内存占用200-500MB属于正常范围
2. 原生编译版本内存占用只有5-10MB，适合资源受限环境
3. 长时间运行后如果内存过高，可以重启XAgent进程
4. 减少上下文历史可以降低内存占用

## 🔒 安全相关问题

### Q1: XAgent会读取我的本地文件吗？
**A**:
- XAgent只会在你明确要求的情况下才会操作文件
- 所有文件操作都在你指定的工作目录范围内
- 敏感文件（如.env、credentials.json）默认会被拦截，需要你明确授权才能访问
- 所有操作都会有日志记录，你可以随时查看

### Q2: XAgent会上传我的代码到第三方服务器吗？
**A**:
- XAgent只会将必要的上下文发送给你配置的AI模型服务
- 不会上传任何代码或数据到其他未经授权的服务器
- 你可以选择本地部署的AI模型，完全在本地运行，数据不会离开你的设备
- 所有网络请求都可以通过代理或防火墙进行监控

### Q3: 可以在生产环境使用吗？
**A**:
- XAgent目前处于活跃开发阶段，建议先在开发/测试环境使用
- 生产环境使用建议做好权限控制和审计
- 重要操作前做好备份，避免意外损失
- 建议定期更新到最新版本，获取安全修复和功能更新
